# 转生为第七王子，随心所欲的魔法学习之路 · 第二季 中日双语字幕

《転生したら第七王子だったので、気ままに魔術を極めます》第 2 期（2025 年，第 13–24 集）的**中日双语字幕**。

日文用官方（Netflix）日文字幕，中文用官方（爱奇艺台湾）中文字幕转成简体后**逐条对着日文原文校对过**——
错译、漏译、说话人标错、术语不统一都改掉了，改动清单见下面。

## 安装 / 使用

1. **下载**：

   ```sh
   git clone https://github.com/leohearts/Dainanaoji-S2-JP-CHS-Bilingual-Subtitles.git
   ```

   或者在仓库页面点 `Code` → `Download ZIP`。

2. **放到视频旁边**：字幕文件名要和视频同名（扩展名前多一段 `.chs-jp` / `.chs`）：

   ```
   Dainanaoji S2 - 13 xxx.mkv
   Dainanaoji S2 - 13 xxx.chs-jp.ass   ← 中日双语
   Dainanaoji S2 - 13 xxx.chs.ass      ← 简体单语
   ```

   mpv / VLC / PotPlayer 都会自动加载同名的外挂字幕，不用手动挂。

3. **选字幕轨**：mpv 会因为文件名排序把 `.chs-jp.ass` 排在前面而**默认选中双语轨**；
   想默认中文单语，在 `~/.config/mpv/mpv.conf` 里加一行 `alang=chs`。播放中按 `j` 也能切换。

4. **装字体**（可选）：不装也不会报错，libass 会自动回退到别的字体，只是字型不同。
   字体和下载链接见下面的[字体](#字体)一节。

字幕适配的是**日版 BD**（H-Enc BDRip），换别的片源可能需要自己调轴，详见[时间轴](#时间轴)。

## 中日双语字幕

中文用原样式，日文用新增的 `JP` 样式（**Zen Maru Gothic**、48 号、加粗、白色，与中文同色），`\an8` 之类的定位跟随原条目。

- **日文源**：Netflix 官方日文日文 CC（`S02E13`–`S02E24`，12 集原档也在 `日文原档/` 里），另有 Amazon SDH 和 TX 电视台版用来交叉核对。
- **时间轴**：日文 CC 比 BD 整体晚 **16.0 秒**（12 集逐集实测，全部都是 +16.0，只有 ep22 是 +16.1），平移后与中文字幕配对。
- **配对**：一条日文 cue 配给与它时间重叠 ≥ 25% 的中文行；一条日文 cue 覆盖多条中文行时，
  优先按日文 cue 自己的内部换行切（Netflix CC 基本是按意群／说话人排的，613 个这种窗口里 404 个直接按行切开），
  行数对不上就在「空格处／标点之后」这些合法断点里挑一个，让切出来的长度比例最接近对应中文行的长度比例。
  切不开的（断点不够）就整条留给第一条，不去切在词中间。5104 条中文里 4651 条带上了日文。
- 没带日文的 453 条：主要是片头／片尾歌词（官方中文字幕有歌词译文，但 Netflix 日文 CC 对 OP/ED 只给了 `♪～`，
  日文歌词见下面的「片头片尾」一节），以及少数中文独有行。
- CC 里的纯音效行（`（ロイドの笑い声）`、`♪～` 等）没有配进去。

## 从繁体转成简体时修掉的问题

简体稿不是从零翻译的，而是拿官方繁体转的。转换字典会带出三类毛病，都已修正：

1. **逗号被吃掉**：整份正文原本 0 个逗号（繁体原文有 64 个），逗号位置变成了空格。
   例：`主人 天亮了` → `主人, 天亮了`。
2. **短语误替换**：`我們的士氣` 里的「的士」被当成粤语词换成了「出租车」，成了 `我们出租车气`。
   → `我们的士气`
3. **台湾异体字残留**：`疗癒` / `奇蹟` / `委讬` / `徬徨` → `疗愈` / `奇迹` / `委托` / `彷徨`

做法：以繁体原文为母本，用 OpenCC（`t2s`）重做转换，再补 12 个 OpenCC 不覆盖的台湾异体字：
妳→你、讬→托、牠→它、祢→您、拚→拼、痺→痹、馀→余、砲→炮、欸→诶、蹋→塌、鍊→练、姊→姐。
「著」按上下文处理（助词转「着」，`著名 / 著作` 保留）。

有 9 处**特意保留原简体的用词**——繁体原文是台湾说法，原简体已改成大陆说法，比照搬原文更合适：

| 位置 | 繁体原文 | 保留 |
| --- | --- | --- |
| ep15 10:47 / ep16 09:18 / ep19 19:09 | 想像 | 想象 |
| ep16 07:20 | 訊號 | 信号 |
| ep20 04:24 / ep23 18:12 | 是說 | 话说 |
| ep20 13:25 | 鍛练（原文自身的错字） | 锻炼 |
| ep22 18:13 | 练子（原文自身的错字） | 链子 |
| ep23 00:36 | 「十誡」 | 「十戒」 |

S1 那套（芝士动物朋友）的日文用的是 `EPSON 太丸ゴシック体Ｂ`，但 EPSON 的字体授权明确禁止这样用

把同一帧分别用它、M PLUS Rounded 1c 和 EPSON 原版渲染出来并排看，它的粗细和圆润度最接近。

## 校对方法

- 逐条与繁体原文比对：每条字幕的文本与原文一致（除上面列出的改动）。
- 程序检查：0 条繁体残留、0 条空字幕。
- 与官方简体 SRT 参考稿交叉比对，差异只剩有意保留的用词。
- 日文与 Netflix CC、Amazon SDH、TX 电视台版三版交叉核对。
- 用 ffmpeg + libass 把字幕烧到片源上抽查渲染（含带 `\an8` 定位的歌词行）。
- 有疑问的句子抽日语音轨，用 Whisper（large-v3-turbo）转录核对。
